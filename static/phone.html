The wall

Checking version…
Update pulls the newest FamilyHub code and restarts, from anywhere (Tailscale). Restart re-reads .env. Reload refreshes the screen. Wake turns it on during the night window.

Family PIN

Checking…
With a PIN on, anything that changes FamilyHub (adding, ticking, settings, lights, the alarm pad) asks for it once on each phone and once on the wall, then remembers it. Looking stays open. Five wrong guesses locks that device out for a minute.

Start fresh
